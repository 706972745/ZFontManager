## 🇨🇳 本分支新增内容

### ✨ 新增功能

- **字体快照**：把当前已启用的字体保存为一组"快照"，随时一键恢复
  - 最多保存 5 个快照，超出自动淘汰最旧的
  - 两种应用方式：**切换到此快照**（停用其他字体）或 **合并到当前启用**（叠加启用）
  - 系统字体也会记录并明确标注，应用快照时**系统字体绝不会被停用**
  - 支持导入/导出（导出文件名自动命名为 `ZFontManager_快照名_导出时间.json`），导入时可选仅导入 / 导入并切换 / 导入并合并
  - 可在字体详情面板用开关把整个字族加入/移出快照，也可右键精细控制
- **启动自动恢复**：每次打开软件自动重新启用上次会话中启用的字体
- **速览 QuickBar**：一键把窗口收成贴在屏幕边缘的透明细线，悬停即展开，鼠标离开自动收回；**Alt + ` 是系统级热键**（Win32 `RegisterHotKey`），别的软件在前台时也能直接唤出速览；**快捷键可在设置里重新录制**（含「恢复默认」），并有一个开关控制「完整界面按快捷键是否跳转到速览」；
  贴屏幕顶边时点「最小化」没有系统那段「飞到任务栏」动画，直接收起消失，还原时在原地直接出现
- **CorelDRAW 支持**：在 Photoshop、Illustrator 之外，新增向 CorelDRAW 的选中文字应用字体
- **版权信息整理**：安装字体按"字族 + 版权"分文件夹归档；导入时保留 License/版权说明文件；
  全库按版权内容搜索；导入 zip 一律移动（不留源副本）
- **黑白灰界面**：全部图标与界面配色统一为黑白灰风格（原版为紫色）

### ⚡ 性能与稳定性（0.9.0 / 0.9.1 压测验证）

- **冷启动又快又有反馈**：字体解析结果按「路径 + 修改时间 + 大小」缓存，之后只解析新增/改动的文件；窗口约 1.5 秒内就出来，骨架屏 + **底部百分比进度条**（完整界面与速览都有），不再对着空桌面干等

- **批量启停千级字体不卡界面**：一次性启用/停用上千字体的命令移到后台线程，
  注册表索引每批只建一次、系统广播每批只发一次——修复旧版整体 O(n²) 导致的假死。
  真机压测：一次性导入 5873 个字体、1639 字族启用 / 2244 字族停用 / 2331 字族恢复启用，
  全程界面可响应、无崩溃。

## 💡 为什么选择 ZFontManager？

如果你在 Linux 上和字体打过交道，你懂那种感受：字体散落在各个文件夹里，预览就得一个个打开文件，想"管理"它们意味着打开终端然后听天由命。Windows 和 macOS 的情况好一些——但好用的工具都要花真金白银。

ZFontManager 一并解决这两个问题：

- **一个应用，三大平台。** 在 Linux、Windows 和 macOS 上都是同样清爽的界面。
- **原生且快速。** 不是套壳网页——启动快，数百个字族滚动如丝般顺滑，在你的桌面上就像原生应用一样自在。
- **说你的语言。** 九种语言，自动跟随系统——English、Deutsch、Español、Français、Português (Brasil)、Русский、日本語、简体中文和繁體中文。
- **属于你。** 免费、开源（GPL-3.0）、无账号、无云端、无遥测。一切都在你自己的电脑上完成。

> [!NOTE]
> ZFontManager 目前为 **0.9.0**（本分支），更新内容见[更新日志](CHANGELOG.md)。日常使用已经非常可靠，如遇到奇怪的问题，欢迎[反馈](../../issues)。

## ✨ 功能导览

### 整个字体库，实时渲染

首次启动时，ZFontManager 会扫描系统的标准字体位置——包括系统级目录和你的个人用户字体——自动建立字体库。你可以在设置里添加额外的监视文件夹，新字体一出现应用就会察觉。

每个字族都以**它自己的字形**显示，而不是列表里一个干巴巴的名字。在顶部的预览框里输入任意一句话——你的品牌名、正在做的标题——**整个字体库**会立刻用它重新渲染。字号滑块可以把预览从小字调到海报大小。

字重和斜体繁多的字体会归入同一张字族卡片。展开卡片，每种样式——Light、Regular、Bold、Black、斜体——都在下面实时渲染。

三种视图，顶栏即可切换：

| 视图 | 用途 |
|---|---|
| **网格** | 宽敞的大卡片——浏览模式 |
| **列表** | 紧凑的行，带样式数、格式和大小——总览模式 |
| **级联** | 一个字族同时显示所有字号——字体爱好者的视图 |

### 启用与停用——核心功能

这正是字体**管理器**和字体**查看器**的分水岭。

庞大的字体库很爽——直到你在设计软件里打开字体菜单，要从 900 个条目里翻找。在 ZFontManager 里**停用**一个字体，会把它从其他应用的字体菜单中移除，**但不会卸载它**。文件原地不动，字体只是去睡觉了。再拨一次开关，它就回来。

- 一次点击（或按 <kbd>空格</kbd>）切换单个字族
- 选中多个字族，批量启用/停用
- 已停用的字体留在库里，柔和地变暗，随时待命
- 只启用部分样式的字族会显示半程开关和"部分启用 · 12 个样式中的 3 个"，绝不会冒充完全启用。一次点击即可开启其余样式

每个平台底层都使用各自正统的机制（见[平台说明](#-平台说明)）——但对用户而言，它就是一个开关。

> [!TIP]
> 让常用字体保持启用，把另外 800 个装饰字体先停用。你的设计软件字体菜单立刻恢复可用，而每个字体依然只有一键之遥。

### 先试用，再决定

还不确定要不要让这个字体常驻你的菜单？右键 → **"启用直到关闭"**，让它只在本次会话中醒来。退出 ZFontManager 时，它会自动回到睡眠状态。在设计软件里试穿一件新字体，之后不用收拾任何残局。

### 在 Photoshop 或 Illustrator 中应用字体

在 Windows 和 macOS 上，右键一个字族 → **"在 Photoshop 中应用…"** 或 **"在 Illustrator 中应用…"**（命令面板里对选中的字族也可用）。ZFontManager 把字体交给正在运行的软件：所有选中的文本图层或文本框会切换到该字体；如果什么都没选，就新建一个以字族名为示例的文本图层。休眠中的字体会先以"直到关闭"方式唤醒，试字永远不会永久安装任何东西。

> [!NOTE]
> 此集成是 0.3.0 的新功能，发布前未能在真实的 Photoshop 或 Illustrator 上充分测试。它会安全地失败（任何问题都只以提示框出现，不会改动你的文档），但如果你遇到异常，请带上应用版本和提示框内容[提个 issue](../../issues)。

### Affinity（Canva）自动启用

在 Affinity 中打开文档时，ZFontManager 可以自动启用文档需要的字体，Affinity 运行期间一直保持，退出后自动停用。不会永久安装任何东西。

文档用到的字体会被**整个字族**一起带入，所以每个字重和斜体都出现在 Affinity 的字体菜单里，而不只是文档碰巧用到的那一个样式。你原本已启用的样式不会被动，Affinity 关闭后依然保持启用。在字体库里匹配不到的字体名会被跳过，而不是随便换一个样式顶替。

在 **设置 → Affinity by Canva 自动启用** 中开启。需要 **Affinity 3.2 或更新版本**，并在 Affinity 中开启 *设置 → Model Context Protocol*（之后重启 Affinity）。

ZFontManager 会在 Affinity 出现后稍等片刻再连接，因为 Affinity 在完成启动之前就接受连接，此时发起请求可能导致它崩溃退出。因此随启动打开的文档所需的字体会晚一小会儿被启用。之后它每半分钟检查一次新打开的文档，复用已知可用的地址和协议。

> [!NOTE]
> Affinity（Canva 版）只提供 Windows 和 macOS 版本，因此该设置在 Linux 上不显示，监视器也不会运行。

### 浏览并下载免费字体

近两千个开源授权的字族——Google Fonts 上的全部内容——直接在应用内获取。在 **设置 → 在线字体浏览器** 中开启后，侧栏会出现 **Online** 区块。按名称搜索、按分类或授权筛选、只看可变字体，一键把字族加入你的字体库。下载来的字族会打上 *Online* 标签，方便查找。

打开一个字族，你的示例文字会实时渲染出来，旁边是授权信息——名称、全文链接，以及 OFL 声明的保留字体名（如有）。预览通过同一个受限客户端获取单个字体文件；把字族加入库时直接复用该文件，不会下载两次。授权文本会与字体一同保存。

这是第一个会联网的功能，因此做得非常谨慎：

- **默认关闭。** 全新安装不会联系任何字体服务商。
- **开启也不发送任何东西。** 只有当你打开 Online 区块搜索或下载时才会发出请求——后台绝不会。
- **搜索在本地进行。** 目录只抓取一次并缓存七天；输入时在你自己的电脑上过滤。服务商看到的是每周一个请求，而不是每次按键一个。
- **只连两个具名主机，且都列在开关下方：** `api.fontsource.org`（目录）和 `raw.githubusercontent.com`（文件）。
- **你的字体库信息不会离开电脑。** "已在库中"标记在本地计算。

文件直接来自 [google/fonts](https://github.com/google/fonts) 仓库——所有镜像的源头——所以你得到的是完整字体，不是为网页优化的子集。这就是为什么下载不用 Bunny Fonts 和 Fontsource 自家 CDN：它们只提供按文字系统切分的网页文件，会装上一堆残缺副本。Fontshare 则因为其授权禁止再分发而不提供。

### 安装字体

把任何东西拖进窗口：

- 单个字体文件（TTF、OTF、TTC、WOFF 等），
- 整个文件夹，
- 甚至 **ZIP 压缩包**——刚从字体网站下载的，无需解压。

然后选择文件的处理方式：

- **加入字体库**——字体原地不动，从原位置注册。适合放在移动硬盘或项目文件夹里的字体。
- **复制到系统文件夹**——字体被复制进你的字体库文件夹，原文件移除。

你可以在 **设置 → 字体库文件夹** 中把库文件夹指到任何地方。大文件拖入时有进度提示，已在库中的文件会被跳过而不是重复添加。

### 一键启用整个字体库

<kbd>Ctrl</kbd> <kbd>A</kbd>（macOS 为 <kbd>⌘</kbd> <kbd>A</kbd>）选中当前视图中的全部字体——整个库，或者你的筛选和搜索收窄后的结果。右键所选即可一次性启用/停用全部，改变主意时还有统一的撤销。命令面板里也有 *全选*。

### 当两个字体重名时

安装一个与库中现有字体冲突的字体时，ZFontManager 会明说，而不是悄悄选边站。详情面板列出涉及的每个文件，告诉你哪一份是当前启用的，并允许你逐个处理——保留、移除或送入回收站。系统字体被标记为受保护，任何方式都无法移除。

### 是回收站，不是碎纸机

卸载字体绝不会悄悄删除任何东西。被移除的字体进入应用内**可恢复的回收站**——实际文件被安全保存。手滑了？打开回收站标签页，点恢复，字体原样回到原位。只有"清空回收站"或单个条目的"永久删除"才真正删除文件，两者都有醒目标识。

### 整理：标签、合集、收藏、备注

四种互补的方式，治好你的字体混乱：

- **标签**——给任何字族打自由格式的标签（"窄体"、"80年代"、"客户X"）。标签显示在侧栏，本身就是即时筛选器。多选后可一次给多个字体打标签。
- **合集**——手动维护的文件夹，按项目或客户组织。右键任何字体 → 合集 → 加入。一个字体可以属于任意多个合集。
- **收藏**——一颗星标记你的主力字体，侧栏有专属视图。选中字体后按 <kbd>F</kbd>。
- **备注**——每个字族一个小文本框，记下那些不记就忘的事：*"仅供客户X授权使用"*、*"字距在 60px 以上会崩"*。

### 什么都能找到

- **按名称搜索**，边输入边出结果（按 <kbd>/</kbd> 跳到搜索框）。
- **点击字体名即可复制**——详情面板中的字族名，或其下方的 PostScript 名。为那些设置是一个文本文件、没有字体选择器的应用准备。
- **常驻托盘**——可选关闭到托盘、随系统启动、启动时最小化。默认全部关闭。
- **显示**全部字体、只有系统自带，或只有你自己安装的。你的字体淹没在几百个系统字里时特别有用。
- 按**分类**筛选——衬线、无衬线、等宽、手写、展示体等等。
- 按**书写系统**筛选——拉丁、西里尔、希腊等等。
- 按**文件格式**筛选——OpenType、TrueType、WOFF 和 WOFF2。
- 按**排版特性**筛选——花饰、风格替换字、自由连字、小型大写、旧式数字和分数。想找有替代字形的面孔，从这里开始。
- 按**字符**筛选——输入任意字符，字体库收窄到真正有这个字形的字体。此功能要读取每个字体文件，所以按需运行而非持续运行。
- **仅可变字体**——一个开关只看灵活的那批。
- **隐藏系统不允许停用的字体**——在 Windows 和 macOS 上，把系统字体放一边，只看你真正能动得了的。
- 按**名称、样式数、文件大小或字形数**排序。

侧栏还能按状态收窄：**已启用**、**启用直到关闭**、**已停用**、**最近导入**和**系统字体**。每一项都能从命令面板直达，不用伸手拿鼠标。侧栏的浏览、合集和标签区块都可以折叠，下次打开时保持折叠。

筛选条件可以叠加，空状态永远会告诉你当前哪些筛选生效——你不会对着一个莫名空白的库发呆。

### 并排对比字体

选中两到四个字族——<kbd>Ctrl</kbd>+点击逐个选，或按住 <kbd>Shift</kbd> 用方向键——窗口底部会出现一个小条，带 **对比** 按钮。点它（或直接按 <kbd>C</kbd>，或右键所选）打开对比视图：同样的预览文字并排渲染、可调大小，让你用自己的眼睛而不是记忆，最终裁定"这三个无衬线里到底哪个是*那个对的选择*"。

### 级联视图

一个字族，从小到大的每个字号，堆叠在一屏之内。字体设计师就是这样评估一款字体的——你能立刻看到它在哪里变糊、哪里细节出彩、脚注字号下是否还站得住。

### 看透一个字体

点击任何字族，详情面板滑入：

- **每种样式**逐个列出，带实时样张和按样式导出
- **可变字体轴**——拖动字重、字宽、倾斜等滑块，实时看预览形变
- **OpenType 特性**——连字、小型大写、风格替换字、旧式数字……先在这里开关看清效果，再去设计软件里启用
- **字符映射**——字体实际包含的每个字形；点击字符即可复制
- **实用信息**——格式、字形数、文件大小、文件路径、声明的授权信息，外加你的标签和备注

### 导出字体样张

右键一个字族 → **导出样张**，得到一张精美的、可分享的 PNG 字体样张——经典的"字母表 + 字号 + 示例文字"图。发给客户选方案（"A 还是 B？"）再合适不过，对方无需安装字体。

你也可以导出字体文件本身（单个样式或整个字族），或者把整个字体列表导出为元数据，交给表格软件处理。

### 命令面板

按 <kbd>Ctrl</kbd><kbd>K</kbd> 然后输入。跳转到任何视图、打开任何合集、切换主题、重新扫描、按名称找字体——应用里的一切都在几次按键之内。如果你用过编辑器或浏览器里的命令面板，这里完全符合你的预期。

### 主题、音效与动效

- **深色和浅色主题**，外加跟随桌面的"跟随系统"。同样的玻璃质感，不同的光线。
- **界面音效**——开关和事件的轻柔合成音反馈。三档：开、轻、关。
- **减弱动效**——把弹性动画换成快速淡入淡出，可独立于（或叠加于）系统偏好。
- **减弱透明度**——把磨砂玻璃换成实心面板。更好读，还去掉了应用最昂贵的绘制项，在老款核显上收益明显。
- **界面缩放**——ZFontManager 启动时测量屏幕可用区域，自动选择一个能把整个界面装下的缩放，小屏或低分辨率显示器看到的是完整布局而不是被裁掉的。保持自动，或在 80% 到 125% 之间手动固定；大显示器上更大的缩放同样有用。
- **首次启动导览**用聚光灯带你过一遍界面，一分钟掌握要点。随时可以在设置里重放。

ZFontManager 首次启动时跟随桌面语言，之后随时可以在 **设置 → 语言**（或命令面板）中更改。

目前可用：**English**、**Deutsch**、**Español**、**Français**、**Português (Brasil)**、**Русский**、**日本語**、**简体中文**、**繁體中文**。

你的标签、合集、收藏和备注才是真正的心血——字体本身随时可以重新下载。设置 → **导出字体库数据**把它们全部存为一个文件；**导入**则合并回来，本机或另一台电脑都行。

## 🌍 翻译

所有界面文案都存放在 [`src/locales/`](src/locales) 下每种语言一个 JSON 文件里。新增一种语言、或者修一句读着别扭的话，都是一个小小的 pull request——不需要 Rust、不需要 TypeScript、不需要构建工具。

- **[docs/TRANSLATING.md](docs/TRANSLATING.md)** — 如何新增语言或修改措辞
- `pnpm i18n:check` — 报告覆盖率、未知键和占位符错误

两种参与方式，都可以：

- **提交 pull request**，附上新的或修正的语言文件。
- **直接提需求。** 开一个 issue 说明你想要的语言，它就会被加上——不需要会 git。作为母语者审阅一份草稿也算贡献，而且往往正是最缺的环节。

未完成的翻译也欢迎：未翻译的部分会回退到英文，半成品语言文件照样能用。复数规则按语言分别处理——检查器会告诉你你的语言需要哪些形式。

## 🧭 平台说明

ZFontManager 使用每个操作系统原生的字体机制——没有黑科技，没有"便携字体文件夹"的把戏。

<table>
<tr><th align="left">平台</th><th align="left">启用机制（大白话版）</th></tr>
<tr>
<td><b>🐧 Linux</b></td>
<td>使用 <i>fontconfig</i>——所有 Linux 应用读取字体走的就是这套系统。停用即告诉 fontconfig 跳过该字体——应用们自然不再提供它。不移动、不删除任何文件。</td>
</tr>
<tr>
<td><b>🪟 Windows</b></td>
<td>使用 Windows 自身的按用户字体注册机制。开关如实反映 Windows 的实际清单：你添加的文件夹里的字体初始显示为<i>未启用</i>，开启时会以你的用户身份就地注册——移动硬盘上也可以。只有 Windows 真正加载成功后字体才算已注册，被 Windows 拒收的文件会显示错误而不是"已启用"的开关。停用即取消注册；文件原地不动。管理你自己的字体不需要管理员权限。</td>
</tr>
<tr>
<td><b>🍎 macOS</b></td>
<td>使用受管制的移开机制：停用的字体被转移到应用管理的专用文件夹，重新启用时恢复到原始位置。</td>
</tr>
</table>

用 **加入字体库** 方式添加的字体在任何平台上都原地不动。在 Linux 和 macOS 上，应用会把它们链接进你的字体文件夹让系统其余部分看到；原始文件绝不移动、复制或删除。

> [!TIP]
> **在 Linux 上请用 `.deb` 或 `.rpm`。** 它们安装干净并使用你系统自己的库。AppImage 并非每次发布都有：GitHub Actions 生成的需要 **FUSE 2**，很多现行发行版默认已不安装，而且它们链接的是构建机器的库，老发行版可能拒绝启动。偶尔提供时只是便利，不是推荐路径。
>
> RPM 注册的包名是 `z-font-manager`，所以查询已装版本用 `rpm -q z-font-manager`，尽管文件名是 `ZFontManager-<version>-1.x86_64.rpm`。

两个集成功能受平台限制，在不适用的平台上自动隐藏：**Photoshop / Illustrator**（Windows 和 macOS）与 **Affinity（Canva 版）**（Windows 和 macOS）。

> [!TIP]
> **在小屏或低分辨率显示器上**，ZFontManager 启动时自适应屏幕可用区域并缩放界面，不会有东西落在任务栏下面或屏幕边缘之外。想自己定，去 设置 → 外观 → *界面缩放*。老显卡上，同一区块的 *减弱透明度* 值得打开。

> [!IMPORTANT]
> 有些应用只在启动时刷新字体列表。如果新启用的字体没有出现在已经打开的应用里，重启那个应用——那是应用的缓存，不是字体丢了。

> [!WARNING]
> **系统字体受保护。** 操作系统画自己界面所需的字体无法在 ZFontManager 中停用或删除，所以你可以放心探索。在 Windows 和 macOS 上，它们的卡片显示一个 **OS** 锁定徽章而不是开关，悬停可见原因。在 Linux 上，fontconfig 可以排除任何字体，所以一切都带开关。

## 🔒 隐私

简短版：**开箱即用，什么都不发送。**

- ❌ 无账号、无注册、无许可密钥
- ❌ 无遥测、无分析、无崩溃上报
- ❌ 你的字体、标签、合集或备注绝不会被上传——没有任何功能会这样做，无论开关
- ✅ 一切都存在你电脑上的本地文件里
- ✅ 全新安装唯一碰网络的情况，是你点击"关于"页里的链接，而那只是打开浏览器

我们宁愿确切告诉你应用能连什么，也不愿让你信任一个形容词。完整清单如下：

| 功能 | 默认 | 联系对象 | 会离开你的电脑吗？ |
|---|---|---|---|
| Affinity 自动启用 | **关** | `localhost:6767` — Affinity 自己的服务器，就在你电脑上 | **不会。** 仅本机回环 |
| 在线字体浏览器 | **关** | `api.fontsource.org`（目录）；`raw.githubusercontent.com`（字体文件与授权文本） | **会** — 你的 IP 和你下载的字体，只发往这两个主机。你现有字体库的任何信息都不会。 |

任一功能关闭时，应用不做任何连接尝试：不运行监视器、不发探测、不抓目录。Affinity 的对话从未离开你的电脑——没有 DNS 查询，没有网络数据包。字体浏览器确实会连两台真实服务器，上表写明了是哪两台、它们收到什么：你的 IP 地址、目录请求，以及你选择下载的字体。两个主机都公开隐私政策，都不是广告网络，且在你主动操作之前不发送任何东西。

未来新增的任何联网功能都会进这张表，默认关闭，并在你开启之前先行披露。

不必只听我们说——全部源代码[公开](https://github.com/TheHolyOneZ/ZFontManager)可查。

## ❓ 常见问题

<details>
<summary><b>停用字体会删掉它吗？</b></summary>
<br>
不会。停用只是把字体从其他应用的字体菜单中隐藏。文件原地不动，字体也留在你的 ZFontManager 库里（显示为变暗）。一次点击即可找回。
</details>

<details>
<summary><b>我不小心卸载了一个字体，它没了吗？</b></summary>
<br>
没有——它在回收站标签页里，实际文件被安全保存。点 <i>恢复</i>，它原样回到原位。只有你明确选择 <i>永久删除</i> 或 <i>清空回收站</i> 时字体才会真正移除。
</details>

<details>
<summary><b>它会动我的系统字体吗？</b></summary>
<br>
不会。操作系统需要的字体受保护——应用不允许你停用或删除它们。
</details>

<details>
<summary><b>支持哪些字体格式？</b></summary>
<br>
常见的桌面格式：TTF、OTF、TTC 集合、WOFF/WOFF2，以及可变字体。你的设计软件能用的，ZFontManager 几乎都能管理。
</details>

<details>
<summary><b>我启用的字体没出现在设计软件里。</b></summary>
<br>
多半是应用本来就开着，只在启动时读取字体列表。重启该应用，字体就在了。（有些应用也有自己的"刷新字体列表"命令。）对 Photoshop 和 Illustrator 可以完全绕开字体菜单：右键字族 → <i>在 Photoshop 中应用…</i> / <i>在 Illustrator 中应用…</i>。
<br><br>
如果只出现部分样式，检查该字族的开关：详情面板里的半程开关和"部分启用"表示还有一些样式没开，一次点击即可全部开启。还是没有？每次启用都会写入 <code>activation.log</code>，包含每个文件向 Windows 或 macOS 提供的名称，以及两个文件声明同名（会导致应用只显示其一）时的警告。提 issue 时附上它：
<ul>
<li><b>Windows：</b> <code>%APPDATA%\ZFontManager\activation.log</code></li>
<li><b>macOS：</b> <code>~/Library/Application Support/ZFontManager/activation.log</code></li>
<li><b>Linux：</b> <code>~/.local/share/ZFontManager/activation.log</code></li>
</ul>
</details>

<details>
<summary><b>能把我的标签和合集搬到另一台电脑吗？</b></summary>
<br>
可以——设置 → <i>导出字体库数据</i> 生成一个备份文件，包含你的标签、合集、收藏和备注。在另一台电脑上导入即可合并。
</details>

<details>
<summary><b>真的免费吗？</b></summary>
<br>
真的免费。免费使用、免费分享，源代码在 GPL-3.0 许可下自由阅读和修改。没有付费档、没有"专业版"、没有解锁。
</details>

<details>
<summary><b>出问题了，去哪里反馈？</b></summary>
<br>
尽管来！在 <a href="../../issues">GitHub issue 区</a>开一个 issue，说明你做了什么、发生了什么。截图很有帮助；凡是和启用字体相关的，<code>activation.log</code>（见上）也有帮助。
</details>

## 🔧 从源码构建

构建它不需要读懂代码——只需装好 [Node.js](https://nodejs.org)（带 `pnpm`）、[Rust](https://rustup.rs) 和你所在平台的 [Tauri 前置依赖](https://tauri.app/start/prerequisites/)。然后：

```sh
git clone https://github.com/706972745/ZFontManager.git
cd ZFontManager
pnpm install
pnpm tauri build
```

构建出的安装包在 `src-tauri/target/release/bundle/`。想要实时开发窗口，用 `pnpm tauri dev`。

<details>
<summary>给维护者：发布新版本</summary>
<br>

1. 更新 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 和 `src/lib/version.ts` 中的版本号，并在 `CHANGELOG.md` 中加入新段落。
2. 推送。GitHub Actions 工作流会构建各平台安装包——Windows `.exe`/`.msi`、macOS Apple Silicon 与 Intel `.dmg`、Linux `.deb`/`.rpm` 及一个 AppImage——并附到草稿 Release。AppImage 只有在真实发行版上验证过才发布；不放也完全可以。
3. 下载构建产物，运行 `node prepare-release.mjs --from <folder>`。它把安装包收集到 `zfontmanager/releases/`，生成 `SHA256SUMS.txt`，并更新下载页的版本、链接、大小与校验表。不随本次发布的安装包在页面上隐藏而非列出。上传 `zfontmanager/`，把更新日志段落粘进草稿，发布。

</details>

<details>
<summary>给好奇的人：它由什么组成</summary>
<br>

| 层 | 技术 |
|---|---|
| 应用外壳与系统集成 | Tauri v2 + Rust |
| 界面 | React 19 + TypeScript |
| 动画 | Motion（弹簧曲线） |
| 构建工具 | Vite + pnpm |

Rust 侧负责一切接触系统的部分——扫描、安装、启用、回收站；界面侧负责渲染、预览和整理。设计原则与产品规格在 <code>docs/</code> 文件夹。

</details>
